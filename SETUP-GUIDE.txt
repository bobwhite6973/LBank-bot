⚠️  IMPORTANT WARNING BEFORE YOU START
-------------------------------------------
This bot trades with UP TO 4x LEVERAGE on futures contracts.
With 4x leverage, a 25% price move against your position
will result in TOTAL LOSS of that position's margin.

Only deposit money you can afford to lose entirely.
The bot has built-in safety guards (stop-loss, daily loss
limit, liquidation guard) but no system eliminates all risk.

Start small. Learn how it behaves. Scale up slowly.

----------------------------------------------------------------
PART 1: GET YOUR API KEYS (do this first, all free)
----------------------------------------------------------------

STEP 1 — Create a Telegram Bot
--------------------------------
1. Open Telegram
2. Search @BotFather and open it
3. Send:  /newbot
4. Name it anything (e.g. LBankTrader)
5. Username must end in "bot" (e.g. mylbanktrader_bot)
6. BotFather sends you a token like:
   1234567890:ABCDefGhIjKlMnOpQrStUvWxYz
7. SAVE THIS TOKEN


STEP 2 — Create your LBank API Key
-------------------------------------
This is the key the bot uses to trade on your LBank account.

1. Log into your LBank account at lbank.com
2. Click your profile icon (top right) → "My Account"
3. Find "API Management" in the left menu
4. Click "Create API"
5. Give it a name: TradingBot
6. IMPORTANT — Enable these permissions:
     ✅ Read
     ✅ Contract Trading (Futures)
     ❌ Withdrawal (do NOT enable this)
7. Complete any 2FA verification
8. You will see:
     API Key: (long string)
     Secret Key: (shown ONCE — save it immediately)
9. SAVE BOTH — the secret key cannot be retrieved again
10. Optional but recommended: add your server IP to the
    whitelist (Railway IP — find it in Railway → Settings)


STEP 3 — Transfer USDT to your Futures account
------------------------------------------------
The bot trades in your LBank Futures wallet, not spot.

1. On LBank, go to Futures section
2. Click "Transfer" to move USDT from Spot → Futures wallet
3. Recommended starting amount: $50-200 USDT minimum
   (bot uses 20% per trade → at $100 that's $20 margin per trade
    with 4x leverage = $80 notional position)
4. You can check your futures balance with /balance in the bot


STEP 4 — Get Telegram API ID and Hash (to read alpha channels)
--------------------------------------------------------------
1. Open your phone browser:  https://my.telegram.org/apps
2. Log in with your phone number
3. Click "API development tools"
4. Fill in: App title = LBankBot, Short name = lbankbot, Platform = Other
5. Click "Create application"
6. Copy:  App api_id  and  App api_hash
7. SAVE BOTH


STEP 5 — Get Moralis API Key (optional but recommended)
-------------------------------------------------------
Adds macro sentiment signals — makes the bot smarter.

1. Go to:  https://admin.moralis.io
2. Sign up free → Web3 APIs → copy your API key
3. SAVE IT

   AUTO_TOP_PAIRS          5

   LEV_TIER_2              25

   LEV_TIER_4              75

PART 5: HOW THE BOT TRADES
----------------------------------------------------------------

SIGNAL FLOW:
  Source 1: LBank ticker → price momentum bullish on BTC_USDT → +2pt LONG
  Source 2: DEX Screener → BTC trending +4% on-chain → +3pt LONG
  Source 3: Telegram → "BTC LONG entry 65000" in channel → +4pt LONG
                                                              ─────────
                                                   Total: 9pt LONG ✅

  Threshold is 5pt → TRADE EXECUTES as LONG BTC_USDT

DYNAMIC LEVERAGE (10x minimum, 100x maximum):
  Score 5-6  → 10x  (threshold just met — minimum leverage)
  Score 7-8  → 25x  (moderate confidence)
  Score 9-10 → 50x  (strong signal, 3+ sources agree)
  Score 11-12→ 75x  (very strong)
  Score 13+  → 100x (all 5 sources agree — maximum leverage)

DIRECTION CONFLICT PROTECTION:
  If LONG score = 6pt AND SHORT score = 5pt simultaneously
  → bot does NOT trade (market is confused = too risky)

POSITION MANAGEMENT:
  Stop loss:        price moves 3% against you → close
  Take profit:      price moves 6% your way → close
  Trailing stop:    as position profits, stop moves with it
                    (locks in gains if price reverses)
  Liquidation guard: if margin loss hits 20% → close
                    (prevents exchange liquidation)
  Daily loss limit: if daily PnL drops $50 → pause for the day

LEVERAGE EXAMPLES (all with $200 balance, 20% margin = $40):

  10x LEVERAGE (weak signal, score 5-6):
    Notional: $400 | BTC position at $65,000 = 0.00615 BTC
    UP 6%:   profit = $400 × 6% = $24 on $40 margin = +60%
    DOWN 3%: loss   = $400 × 3% = $12 on $40 margin = -30% → SL closes

  50x LEVERAGE (strong signal, score 9-10):
    Notional: $2,000 | BTC position = 0.0308 BTC
    UP 1%:   profit = $2,000 × 1% = $20 on $40 margin = +50%
    DOWN 0.5%: loss = $2,000 × 0.5% = $10 on $40 margin = -25% → SL closes
    (SL auto-tightens to 0.5% at 50x to prevent liquidation)

  100x LEVERAGE (all sources agree, score 13+):
    Notional: $4,000 | BTC position = 0.0615 BTC
    UP 0.5%: profit = $4,000 × 0.5% = $20 on $40 margin = +50%
    DOWN 0.3%: loss = $4,000 × 0.3% = $12 on $40 margin = -30% → SL closes
    (SL auto-tightens to 0.3% at 100x — this is scalping speed)
    Liquidation at: 1% move against you = full margin gone

  ⚠️  100x trades close VERY fast. A 1% candle wipe can liquidate
      before the bot even gets the price update. Only happens when
      all 5 signal sources agree simultaneously (score 13/15).

----------------------------------------------------------------
RISK MANAGEMENT TIPS
----------------------------------------------------------------

START CONSERVATIVE — then scale up:
  Week 1-2: Lower MARGIN_PERCENT to 10 (smaller positions)
  Week 3+:  If profitable, raise to 15-20%

LIMIT YOUR DAILY LOSS:
  Set MAX_DAILY_LOSS to 10-15% of your total balance
  Example: $200 balance → set MAX_DAILY_LOSS to 25

WATCH YOUR LEVERAGE:
  4x is already aggressive for a bot
  If losing, consider setting LEVERAGE=2 in Railway Variables

DON'T OVER-POSITION:
  Keep MAX_POSITIONS at 2-3
  Having 5 positions open at 4x = extremely high risk

ADD QUALITY SIGNAL CHANNELS:
  The more good Telegram futures channels you add,
  the better the consensus quality
  Look for channels with track records, not random groups


----------------------------------------------------------------
TROUBLESHOOTING
----------------------------------------------------------------

"API error: 35 Insufficient balance"?
  → Transfer more USDT to your LBank Futures account
  → Or lower MARGIN_PERCENT in Railway Variables

"API error: 7 Invalid Session"?
  → Your API key expired (LBank keys not bound to IP expire in 30 days)
  → Create a new API key on LBank and update Railway Variables

"API error: 8 Contract product does not exist"?
  → The pair format is wrong — use format: BTC_USDT not BTC/USDT

No trades opening?
  → Signal threshold might not be reached
  → Add more Telegram signal channels
  → Lower MIN_BUY_SCORE from 5 to 4 in Railway Variables
  → Check /sources — ensure sources are active

Bot restarting repeatedly?
  → Railway → Deployments → View Logs for the error
  → Most common: wrong API key or wrong variable format
